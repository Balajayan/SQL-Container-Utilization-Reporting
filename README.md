# Container Utilization Reporting Query

## Overview

This project contains a SQL query developed for container utilization reporting and logistics analysis.

The query combines shipment, container, supplier, customer and part information from multiple business tables to generate operational reports.

## Business Objective

The objective of this solution is to:

- Analyze container utilization
- Track shipment movement
- Monitor container volume (CBM)
- Review part-level shipment details
- Support logistics reporting

## SQL Features Used

- INNER JOIN
- DISTINCT
- GROUP BY
- HAVING
- ORDER BY
- Calculated Fields
- Date Functions
- String Concatenation

## Key Metrics

- Container Number
- ASN Number
- RFS Number
- Container Dimensions
- Container CBM
- Shipped Quantity
- Part Number
- Part Weight
- Carrier Information

## Business Impact

- Reduced manual reporting effort
- Improved shipment visibility
- Faster logistics analysis
- Better container utilization tracking
